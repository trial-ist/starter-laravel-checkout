# Northwind Supply

A small Laravel shop. Customers pick products, optionally enter a discount
code, and place an order.

## The problem

Customers report that orders using a discount code are sometimes charged the
full price. The app is already running in your workspace: try it in the
**Preview** on the right. Discount codes you can use: `SAVE10`, `HALFPRICE`,
`WELCOME5`.

## What we'd like you to do

1. Reproduce the bug.
2. Fix it, and add or update tests so it can't come back.
3. Leave a short note in `NOTES.md` explaining the cause and your fix.
